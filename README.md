# Chuyên Đề: Bài Giảng Tin Học 10 - AI (Trí Tuệ Nhân Tạo)

## 📌 Giới thiệu
Repository này đóng vai trò là "bộ não" trung tâm, nơi quản trị mã nguồn, giáo án, tài nguyên bài giảng và tài liệu học tập cho chuyên đề **Tin học 10 - Trí tuệ nhân tạo (AI)** trước khi tích hợp và cấp quyền truy cập cho Antigravity.

## 🎯 Mục tiêu
- Quản trị phiên bản mã nguồn và tài liệu giảng dạy một cách chuẩn mực.
- Cung cấp cấu trúc bài học, slide, bài tập thực hành về AI và lập trình.
- Đồng bộ hóa tài nguyên với các công cụ AI Assistant (Antigravity).

## 📂 Cấu trúc thư mục dự kiến
```
bai-giang-tin-hoc-10-ai/
├── README.md               # Tài liệu giới thiệu dự án
├── .gitignore              # Danh sách các file/thư mục bỏ qua khi commit
├── giao-an/                # Kế hoạch bài dạy, giáo án chi tiết
├── bai-giang/              # Slide trình chiếu, bài giảng điện tử
├── tai-nguyen/             # Dữ liệu mẫu, hình ảnh, tài liệu tham khảo
└── ma-nguon/               # Code mẫu, bài tập thực hành Python / AI
```

## 🚀 Hướng dẫn sử dụng
1. Clone repository về máy tính:
   ```bash

   ```
